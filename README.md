# Решение задачи коммивояжёра методом ветвей и границ

Курсовая работа по дисциплине «Исследование операций» / «Методы оптимизации»

## Краткое описание

Программа находит **точное оптимальное решение** задачи коммивояжёра (TSP) с помощью классического метода ветвей и границ (Branch and Bound). Алгоритм гарантирует нахождение минимального замкнутого маршрута, проходящего через каждый город ровно один раз.

Для несимметричных и симметричных матриц расстояний произвольного размера (ограниченного лишь временем вычислений и памятью) программа определяет:
- минимальную стоимость маршрута,
- порядок посещения городов.

## Используемый алгоритм

### Метод ветвей и границ

Алгоритм строит дерево всех возможных продолжений частичного маршрута, начиная с города 0.  
В каждом узле дерева вычисляется нижняя граница стоимости любого допустимого продолжения. Если эта граница не меньше уже найденного рекорда, ветвь целиком отсекается, что значительно сокращает перебор.

### Корректность

Гарантируется, что нижняя оценка никогда не превышает реальной минимальной длины оставшегося пути. Поэтому отсекаются только те ветви, которые заведомо не улучшат текущий рекорд. В результате алгоритм находит точное глобальное оптимальное решение.

## Компиляция и запуск

```bash
g++ -std=c++11 -o tsp TSP.cpp main.cpp
./tsp
```

## Пример ввода данных

Сначала строка заголовков, потом строки данных:
```bash
0 1 2 3
0 0 10 15 20
1 10 0 35 25
2 15 35 0 30
3 20 25 30 0
```
**Вывод:**
**Минимальная стоимость: 80**
**Оптимальный маршрут: 0 1 3 2 0**
